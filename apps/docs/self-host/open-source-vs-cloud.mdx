Lumvika Cloud is the same Lumvika, hosted, plus what only a hosted service can offer: machines ready in seconds, included model credit, paid data, emails. The coworkers, the chat, the board and the Steward are the same code in both.

## Side by side

| | Open source | Lumvika Cloud |
|---|---|---|
| Coworkers, chat, memory, skills, schedules | ✅ | ✅ |
| Projects, issues, review, goals, teams, channels, Chat | ✅ | ✅ |
| Services catalog, MCP, Composio | ✅ | ✅ |
| Template library | Your own templates | ✅ |
| A computer for each workspace | You host it, one command attaches it | Ready in 30 seconds |
| AI models | Your keys or subscriptions | Included credit, or your keys |
| LinkedIn Pro, WhatsApp Pro | | ✅ |
| Paid data (leads, SEO, social) | | ✅ |
| Email notifications and invitations | | ✅ |
| Updates | Each release | Continuous |
| Support | Community | ✅ |

On your install there is no plan and no limit: unlimited coworkers, unlimited seats, every model tier.

## What is not in the open source build

Each item below, and what to do instead.

### Managed models with included credit

Lumvika Cloud plans include model credit, so a coworker works with no key at all. On your install, the same Lumvika models run on your `OPENROUTER_API_KEY`, with no credit counted, and you can connect your own provider keys or your Claude or ChatGPT plan. See [AI models](/self-host/models).

### LinkedIn Pro and WhatsApp Pro

Two paid apps of Lumvika Cloud that act on a LinkedIn or WhatsApp account for a coworker. They are switched off here. For the same jobs, connect an MCP server for LinkedIn or WhatsApp, or the LinkedIn app through [Composio](/self-host/services#composio).

### Paid data

On Lumvika Cloud, coworkers can buy data by the call: lead lists, SEO metrics, social profiles. Here, add those providers (Apollo, Semrush and the like) as services or MCP servers, with your own API keys.

### Email notifications and invitations

This build sends no email of its own. Notifications show in the app. An invitation is saved, and you hand its link to the person yourself: see [Invitations](/self-host/administration#invitations). Sign-in codes still go out, through Resend or your SMTP server.

### The template library and the creator program

The template library is part of Lumvika Cloud and does not ship with this build. There is no checkout, no payout and no creator program either. On your install, the library holds the templates you make: [create your own](/templates/create).

### The Weekly Rewind

The weekly recap of what your coworkers did is not part of this build.

### The iOS app

The Lumvika app for iPhone connects to your install too, with sign-in by email code and no push notifications: see [iPhone app](/self-host/mobile).

### Sign-in by phone, Google and Apple

Lumvika Cloud also signs people in by SMS, Google and Apple. Here, sign-in is by email code. Google and Apple can be turned on with an OAuth app of your own at each: see [Sign-in](/self-host/configuration#sign-in).

### Support

Self-hosted installs get community support on GitHub. Read [Troubleshooting](/self-host/troubleshooting) first. An issue on GitHub with the logs and the steps to reproduce gets a look; one without is closed with a link to this guide.
