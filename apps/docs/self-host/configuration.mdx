Lumvika reads its settings from `.env`, next to `docker-compose.yml`. [`.env.example`](https://github.com/schnebel-technologie/lumvika/blob/main/.env.example) lists every variable with a comment, in the groups below. Every one is optional: without `.env`, Lumvika runs on `http://localhost:3000`, generates its secrets on the first start, and sends its emails to the mail catcher. On a server, set the public addresses and a way of sending email.

<Note>
  After changing `.env`, run `docker compose up -d`: it recreates the containers that read it. The app writes `NEXT_PUBLIC_APP_URL`, `NEXT_PUBLIC_STORAGE_URL`, `NEXT_PUBLIC_OAUTH_PROVIDERS` and `ADMIN_EMAILS` into its pages when it starts. Only the captcha site keys and `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN` are baked in by a build: they need [your own build](/self-host/install#build-the-images-yourself).
</Note>

## Version

| Variable | Default | What it does |
| --- | --- | --- |
| `LUMVIKA_VERSION` | `latest` | The tag of the two images: `latest`, a minor like `0.5` (its patches), or an exact `0.5.1`. |

## The address people open

| Variable | Default | What it does |
| --- | --- | --- |
| `NEXT_PUBLIC_APP_URL` | `http://localhost:3000` | The address people open in their browser, without a trailing slash. Sign-in links, invitations and the servers you pair all point there. |
| `LUMVIKA_APP_PORT` | `3000` | The port of this machine docker compose publishes the app on. |

## Postgres

docker compose runs Postgres 17 with pgvector, in the `postgres-data` volume, and does not publish it outside Docker.

| Variable | Default | What it does |
| --- | --- | --- |
| `POSTGRES_PASSWORD` | generated | The password of that Postgres. Set once: Postgres keeps the password it was created with, so changing it later locks the app out. |
| `DATABASE_URL` | empty | A Postgres of your own instead, 17 with the `vector` extension available, as `postgres://user:password@host:5432/database`. Empty means the one docker compose runs. |
| `DATABASE_POOL_MAX` | `10` | How many connections the app opens at most. Not in `.env.example`. |

## Email

People sign in with a code sent by email. With neither of the first two, every email lands in the mail catcher docker compose runs, at `http://localhost:3003` on that machine only: enough to try Lumvika alone, not for a team.

| Variable | Default | What it does |
| --- | --- | --- |
| `RESEND_API_KEY` | empty | Sends every email through [Resend](https://resend.com). |
| `SMTP_URL` | empty | Sends every email through this SMTP server when `RESEND_API_KEY` is empty, as `smtps://user:password@host:465`. |
| `RESEND_FROM` | Resend's test sender | The sender of sign-in codes and notifications, as `Name <address>`. With Resend, an address on a domain verified there: the test sender only delivers to the address of your Resend account. |
| `RESEND_MARKETING_FROM` | Resend's test sender | The sender of reminders and nudges, ideally on a domain of its own. |
| `RESEND_REPLY_TO` | none | Where replies to every email go. |
| `LUMVIKA_MAIL_PORT` | `3003` | The port the mail catcher's inbox is published on, on `127.0.0.1` only. |

## File storage

docker compose runs an S3-compatible store ([RustFS](https://rustfs.com)) in the `storage-data` volume. The `migrate` step creates its buckets.

| Variable | Default | What it does |
| --- | --- | --- |
| `S3_ACCESS_KEY_ID` | `lumvika` | The access key of the store. |
| `S3_SECRET_ACCESS_KEY` | generated | Its secret key. |
| `LUMVIKA_STORAGE_PORT` | `3002` | The port of this machine docker compose publishes the store on. |
| `NEXT_PUBLIC_STORAGE_URL` | `http://localhost:3002` | The address a browser loads files from: avatars, logos, template images. On a server, its `https` domain. See [On a server](/self-host/install#on-a-server). |
| `S3_ENDPOINT` | empty | Another S3-compatible store instead (Cloudflare R2, AWS S3, MinIO): its API address. Empty means the one docker compose runs. |
| `S3_REGION` | `auto` | The region of that store. |
| `S3_BUCKET_PREFIX` | empty | A prefix for every bucket name, when the account holds other buckets. |

## Sign-in

| Variable | Default | What it does |
| --- | --- | --- |
| `BETTER_AUTH_SECRET` | generated | Signs the sessions. Changing it signs everyone out. |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | empty | Sign-in with Google, from an OAuth client of the [Google Cloud console](https://console.cloud.google.com/apis/credentials). Its redirect URI is `<NEXT_PUBLIC_APP_URL>/api/auth/callback/google`. |
| `APPLE_CLIENT_ID`, `APPLE_CLIENT_SECRET` | empty | Sign in with Apple, from a Services ID of your Apple developer account. Its return URL is `<NEXT_PUBLIC_APP_URL>/api/auth/callback/apple`. |
| `APPLE_APP_BUNDLE_IDENTIFIER` | empty | The bundle id of your build of the iOS app, for Sign in with Apple from the app. |
| `NEXT_PUBLIC_OAUTH_PROVIDERS` | empty | `google`, `apple` or `google,apple` adds those buttons to the sign-in page. Set the provider's id and secret above first. |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | empty | The site key of a Cloudflare Turnstile captcha on sign-up. Baked in by a build: needs [your own build](/self-host/install#build-the-images-yourself). |
| `TURNSTILE_SECRET_KEY` | empty | Its secret key. |
| `NEXT_PUBLIC_HCAPTCHA_SITE_KEY` | empty | The site key of an hCaptcha puzzle, shown to a visitor Turnstile could not vouch for, or to every visitor when Turnstile is not set. Baked in by a build, like Turnstile's. |
| `HCAPTCHA_SECRET_KEY` | empty | Its secret key. Without any captcha secret, no captcha. |

## The engine of your first workspace

| Variable | Default | What it does |
| --- | --- | --- |
| `LUMVIKA_ENGINE_API_KEY` | generated | The key shared by the app and the engine docker compose starts next to it. The app calls the engine with it, and the engine calls the app back with it. |
| `LUMVIKA_ENGINE_PORT` | `3001` | The port docker compose publishes that engine on, on this machine. |
| `LUMVIKA_ENGINE_BROWSER_URL` | `http://localhost:3001` | The address a browser reaches that engine at, to watch a coworker's screen. On a server, its `https` domain. See [On a server](/self-host/install#on-a-server). |

## AI

| Variable | Default | What it does |
| --- | --- | --- |
| `OPENROUTER_API_KEY` | empty | Runs the Steward, the helpers behind it (company research, naming, ideas) and the [Lumvika models](/self-host/models) every coworker starts on. Without it, the Steward skips the guided onboarding, and the Steward and the coworkers run on the AI provider you connect. |
| `LUMVIKA_EMBED_API_KEY` | empty | An OpenRouter key for embeddings. It turns on semantic search of the services catalog and of the coworkers' memories. Without it, both fall back to keyword search. |

## Admins

| Variable | Default | What it does |
| --- | --- | --- |
| `ADMIN_EMAILS` | empty | Comma-separated emails that see the admin switches in the app. Empty means nobody. See [Administration](/self-host/administration). |

## Secrets

Every secret marked "generated" on this page is generated on the first start, into the `secrets` volume, when `.env` leaves it empty. A value in `.env` always wins. Keep them stable: changing one invalidates what it already signed. To copy the generated ones into `.env`, see [The rest of `.env`](/self-host/install#4-the-rest-of-env).

| Variable | Default | What it does |
| --- | --- | --- |
| `STEWARD_HUB_TOKEN_SECRET` | generated | Signs the token the Steward calls the app with. |
| `STEWARD_HUB_TOKEN_REQUIRED` | `1` | Makes the app refuse a Steward call without a valid token. `0` lets such a call through and logs it. Leave it at `1`. |
| `BOARD_IMAGE_SECRET` | generated | Signs the board images the app captures for sharing. |
| `UNSUBSCRIBE_SECRET` | generated | Signs the unsubscribe links of the emails. |
| `PUBLISHED_ACCESS_SECRET` | generated | Signs the access to the sites and files the coworkers publish. |
| `MOBILE_OAUTH_TICKET_SECRET` | generated | Signs the hand-off of a Google or Apple sign-in back to the iOS app. |

## Optional services

Each one switches a feature on. Empty means the feature is off, and the rest of Lumvika works.

| Variable | Default | What it does |
| --- | --- | --- |
| `COMPOSIO_API_KEY` | empty | Connects 2,000+ apps by OAuth through [Composio](https://composio.dev). See [Composio](/self-host/services#composio). |
| `BRAVE_SEARCH_API_KEY` | empty | Web search for the coworkers, through the [Brave Search API](https://brave.com/search/api). |
| `FIRECRAWL_API_KEY` | empty | Reading websites through [Firecrawl](https://firecrawl.dev), including your company site when the Steward builds the Brain. |
| `APIFY_TOKEN` | empty | LinkedIn and Google Maps research during onboarding, through [Apify](https://apify.com). |
| `NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN` | empty | Product analytics with [PostHog](https://posthog.com). Off when empty, and the cookie banner only shows when it is set. Baked in by a build: needs [your own build](/self-host/install#build-the-images-yourself). |

## Set by docker compose

`docker-compose.yml` sets these itself. You do not put them in `.env`, except where a row says so.

| Variable | Value | What it does |
| --- | --- | --- |
| `DATABASE_URL` | `postgres://lumvika:<POSTGRES_PASSWORD>@postgres:5432/lumvika` | Where the app and the `migrate` step reach Postgres, unless you set your own. |
| `SMTP_URL` | `smtp://mailpit:1025` | The mail catcher, unless you set your own SMTP server. |
| `S3_ENDPOINT` | `http://storage:9000` | Where they reach the file store, unless you set your own. |
| `LUMVIKA_ENGINE_URL` | `http://engine:3000` | Where the app reaches the engine of the first workspace, inside Docker. |
| `LUMVIKA_HUB_BASE_URL` | `http://app:3000` | Where that engine calls the app back. |
| `LUMVIKA_LOG_LEVEL` | `info` | How much the engine logs: `fatal`, `error`, `warn`, `info`, `debug` or `trace`. You can set it in `.env`. |

## Embeddings

Also not in `.env.example`, and rarely needed.

| Variable | Default | What it does |
| --- | --- | --- |
| `LUMVIKA_EMBED_BASE_URL` | `https://openrouter.ai/api/v1` | Any OpenAI-compatible endpoint for embeddings. |
| `LUMVIKA_EMBED_MODEL` | `openai/text-embedding-3-small` | The embedding model. The seeded catalog is embedded with this one, in 1536 dimensions: keep it unless you re-embed the catalog. |

## Engine variables

An engine started by hand, on a [server](/self-host/servers), reads these.

| Variable | Default | What it does |
| --- | --- | --- |
| `LUMVIKA_HUB_URL` | empty | The address of your app. With a pairing token, the server attaches itself there. |
| `LUMVIKA_PAIR_TOKEN` | empty | The one-time token from **Servers > Add server**. |
| `LUMVIKA_PUBLIC_URL` | empty | The address the app reaches this server at. Without it, the app uses the address the request came from, on port 3000. |
| `LUMVIKA_API_KEY` | generated | The engine's key. When empty, a paired server makes one up and keeps it in `/data/engine.key`. |
| `LUMVIKA_DATA_DIR` | `/data` in the image | Where the engine keeps everything. Mount a volume there. |
| `LUMVIKA_PORT` | `3000` | The port the engine listens on. |
| `LUMVIKA_DESKTOP` | on | `off` turns off the desktop screen and the computer tools. |
| `LUMVIKA_LOG_LEVEL` | `info` | How much the engine logs. |
